# BiziBox

**BiziBox** — личное приложение «сообщения и дела в одном окне». Локальное и приватное: все данные хранятся на вашем компьютере в зашифрованном SQLite, в облако ничего не уходит.

Объединяет **Telegram, Email и ВКонтакте** в один инбокс, ведёт контакты, каталог товаров, заказы, задачи и календарь, напоминает о делах и днях рождения.

---

## Установка (3 простых шага)

### 1. Скачайте BiziBox.exe

Зайдите на [страницу релизов](https://github.com/yourolga777/BiziBox-3/releases/latest) → раздел **Assets** → скачайте файл `BiziBox.exe`.

> Если на странице релизов пусто — последняя версия ещё не опубликована, загляните позже.

### 2. Положите файл в отдельную папку

Например, `D:\BiziBox`. Приложение **portable**: всё (база, настройки каналов, вложения) хранится в папке `data\` рядом с exe. Папку не удаляйте — в ней ваши данные.

### 3. Запустите

Двойной клик по `BiziBox.exe`. Окно консоли не появляется: приложение запускается в фоне и само открывает браузер с интерфейсом. В системном трее появится иконка **BiziBox** (пункты «Открыть BiziBox» / «Выход»).

**Обновление:** скачайте новый `BiziBox.exe` и замените старый файл — данные в `data\` сохранятся.

## Первый запуск

При первом запуске откроется настройка (онбординг):

1. **Логин** — любое имя (под него создаётся папка с данными).
2. **Каналы** — подключите Telegram, Email и/или ВКонтакте (можно пропустить и подключить позже).
3. **Прокси/VPN** — только если Telegram заблокирован в вашей сети.

Хотите просто посмотреть, как всё работает? Нажмите **«Попробовать демо с примерами данных»** — приложение наполнится демо-данными без регистрации.

## Возможности

- **Входящие** — Telegram, Email и ВКонтакте в одном инбоксе; сферы (Работа / Личное / Каналы / Другое / Спам), папки и подпапки, фильтры по каналам, спам, массовая классификация.
- **Контакты** — сферы, метки и папки, заметки, дни рождения, объединение дублей, импорт CSV.
- **Каталог товаров** — товары, поставщики, цены, остатки, CSV-импорт/экспорт.
- **Заказы** — канбан (Новый → В работе → Отправлен → Завершён), состав, суммы, оплата, комментарии, экспорт CSV.
- **Задачи** — канбан, дедлайны, напоминания, повторяющиеся задачи.
- **Календарь** — задачи, события, дни рождения; виды месяц / неделя / день.
- **Дашборд** — «Пульс бизнеса», воронка продаж, ближайшие дела и дни рождения.
- **Режим канала** — для каждого канала: «Оба направления», «Только входящие» или «Только исходящие».
- **Безопасность** — локальные данные (SQLite + Fernet-шифрование), ничего не уходит в облако.
- **Бэкап** — экспорт/импорт всех данных одним зашифрованным файлом.
- **PWA** — работает офлайн, устанавливается на устройство.

## Для разработчиков

### Стек

- **Backend:** Python 3.13, FastAPI, SQLAlchemy 2.0 (async), SQLite, Alembic
- **Frontend:** React 19, TypeScript, Vite, Tailwind CSS, PWA
- **Проверки:** pytest, ruff, mypy, ESLint, Vitest

### Запуск из исходников

```powershell
# Backend
cd backend
.venv\Scripts\python.exe -m uvicorn app.main:app --port 7910

# Frontend (второй терминал; прокси /api -> localhost:7910)
cd frontend
npm install
npm run dev
```

Откройте `http://localhost:5173`.

### Проверки

```powershell
# Backend
cd backend
.venv\Scripts\python.exe -m ruff check app
.venv\Scripts\python.exe -m pytest tests -q
.venv\Scripts\python.exe -m mypy app

# Frontend
cd frontend
npm run lint
npm test
npm run build
```

### Сборка exe

```powershell
cd frontend
npm run build
cd ..\backend
.venv\Scripts\python.exe -m PyInstaller BiziBox.spec --noconfirm
```

Готовый файл: `backend\dist\BiziBox.exe`.
