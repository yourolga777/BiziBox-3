# BiziBox

**BiziBox** — личное PWA-приложение «сообщения и дела в одном окне». Локальное, приватное: все данные хранятся на вашем устройстве в зашифрованном SQLite.

Объединяет Telegram и Email в один inbox, ведёт контакты со сферами и множественными метками, управляет товарами, заказами, задачами и календарём, напоминает о делах и днях рождения.

## Установка

### 1. Скачайте `BiziBox.exe`

Скачайте `BiziBox.exe` со [страницы релизов](https://github.com/yourolga777/BiziBox-2/releases/latest): раздел **Releases** → последний релиз → файл `BiziBox.exe`.

> Если на странице релизов пока пусто — ближайшая версия ещё не опубликована, загляните позже.

### 2. Поместите файл в отдельную папку

Например, `D:\BiziBox`. Приложение portable: все данные (база, настройки каналов, вложения) создаются в папке `data\` рядом с exe.

### 3. Запустите

Двойной клик по `BiziBox.exe`. Окно консоли не появляется: приложение запускается в фоне, открывает браузер с интерфейсом, а в системном трее появляется иконка **BiziBox** («Открыть BiziBox» / «Выход»).

**Обновление:** скачайте новую версию `BiziBox.exe` и замените старый файл — данные в папке `data\` сохранятся.

Подробная инструкция — в [руководстве пользователя](docs/user-guide.md).

## Возможности

- **Входящие** — Telegram и Email в одном inbox; папки и подпапки, сферы, фильтры по каналам, спам, массовая классификация.
- **Контакты** — сферы (Работа / Личное / Каналы / Спам / Другое), **множественные метки и папки** (контакт может быть «Друзья» и «Заказчик» одновременно), дополнительные идентификаторы, заметки, дни рождения, объединение дублей.
- **Классификация** — дерево сферы → папки → подпапки; автосвязь папки с меткой (кладёшь в «Поставщики» → метка «Поставщик»).
- **Каталог товаров** — товары, поставщики, остатки, цены, CSV-импорт/экспорт; поставщики связаны с контактами.
- **Заказы** — канбан, состав заказа, комментарии, статусы.
- **Задачи** — канбан, дедлайны, напоминания, повторяющиеся задачи.
- **Календарь** — задачи, события, дни рождения; виды месяц / неделя / день.
- **Безопасность** — локальные данные (SQLite + Fernet-шифрование), ничего не уходит в облако.
- **Бэкап** — экспорт/импорт всех данных одним зашифрованным файлом.
- **PWA** — работает офлайн, устанавливается на устройство.

## Стек

- **Backend:** Python 3.13, FastAPI, SQLAlchemy 2.0 (async), SQLite, Alembic
- **Frontend:** React 19, TypeScript 5.6+, Vite 6, Tailwind CSS 4, PWA (vite-plugin-pwa)
- **Проверки:** pytest, ruff, mypy, ESLint, Vitest

## Запуск для разработки

```powershell
# Backend (dev)
cd backend
.venv\Scripts\python.exe -m uvicorn app.main:app --port 7910

# Frontend (dev, прокси /api -> localhost:7910)
cd frontend
npm install
npm run dev
```

Откройте `http://localhost:5173`.

## Проверки

```powershell
# Backend
cd backend
.venv\Scripts\ruff.exe check .
.venv\Scripts\python.exe -m pytest tests -q
backend\.venv\Scripts\mypy.exe backend

# Frontend
cd frontend
npm run lint
npm test
npm run build
```
