# BiziBox — руководство пользователя

BiziBox — личное приложение «сообщения и дела в одном окне». Объединяет Telegram и Email в единый инбокс, ведёт контакты со сферами и множественными метками, управляет каталогом товаров, заказами, задачами и календарём, напоминает о делах и днях рождения. Работает локально: все данные хранятся на вашем устройстве в зашифрованной базе, ничего не уходит в облако.

---

## 1. Установка и запуск

### Системные требования

- Windows 10/11 (64-бит)
- 2 ГБ ОЗУ, ~1 ГБ свободного места

### Portable-версия (рекомендуется)

1. Скачайте `BiziBox.exe` со [страницы релизов](https://github.com/yourolga777/BiziBox-2/releases/latest).
2. Поместите файл в отдельную папку (например, `D:\BiziBox`).
3. Запустите `BiziBox.exe` — окно консоли не появляется, приложение запускается в фоне и само открывает браузер.
4. В системном трее появится иконка **BiziBox**: «Открыть BiziBox» / «Выход».

Все данные создаются рядом с exe: в папке `data\users\<ваш_логин>\` хранятся база, настройки каналов и вложения.

**Обновление:** скачайте новый `BiziBox.exe` и замените старый файл — данные в папке `data\` сохранятся.

### Запуск из исходного кода

```powershell
# Backend
cd backend
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
uvicorn app.main:app --port 7910

# Frontend (второй терминал)
cd frontend
npm install
npm run dev
```

Откройте `http://localhost:5173`.

## 2. Первый запуск и онбординг

При первом запуске откроется мастер настройки из четырёх шагов:

1. **Telegram** — введите логин (по нему создаётся ваша папка данных) и, при желании, номер телефона и пароль 2FA.
2. **Email** — адрес, пароль, серверы IMAP/SMTP (порты 993/465 по умолчанию).
3. **Прокси / VPN** — выберите, как BiziBox будет подключаться к Telegram (см. ниже).
4. **Готово** — проверьте данные и завершите настройку.

Логин можно ввести, а каналы подключить позже в разделе «Каналы». Шаги переключаются кнопкой **«Далее»**.

### Выбор сети на шаге «Прокси / VPN»

- **Напрямую (без VPN и прокси)** — Telegram открывается на этом компьютере как обычно.
- **Системный VPN** — OpenVPN, WireGuard, Happ, Mullvad, Proton VPN и др. Работают на уровне системы, ничего настраивать не нужно.
- **Свой прокси** — v2rayN, Clash, Nekoray, MTProto и др. Раскройте поля и укажите локальный адрес (тип / хост / порт, обычно `127.0.0.1:порт`).

Если не знаете, что у вас за сервис — раскройте **«Я не знаю, что у меня за сервис»**, введите название, и BiziBox подскажет, что выбрать и что вводить.

## 3. Разделы приложения

| Раздел | Что делает |
|---|---|
| **Дашборд** | Сводка сообщений, задач, контактов, непрочитанные диалоги. |
| **Входящие** | Единый инбокс Telegram и Email: папки и подпапки, сферы, каналы, спам. |
| **Контакты** | Карточки людей и компаний: сферы, метки, папки, идентификаторы, объединение дублей. |
| **Каталог товаров** | Товары, поставщики, остатки и цены, CSV-импорт/экспорт. |
| **Заказы** | Канбан заказов, состав, комментарии, статусы. |
| **Задачи** | Канбан «новые / в работе / выполнено», дедлайны, повторяющиеся задачи. |
| **Календарь** | Задачи, события и дни рождения; виды «месяц / неделя / день». |
| **Каналы** | Подключение и настройка Telegram и Email. |
| **Архив** | Удалённые контакты, сообщения, товары и задачи. |
| **Настройки** | Тема, уведомления, сеть (VPN/прокси), экспорт/импорт данных. |

Внизу бокового меню — **Справка** и **Выход** (пройти онбординг заново, данные сохраняются).

## 4. Классификация контактов (сферы, метки, папки)

Каждый контакт можно классифицировать по нескольким измерениям одновременно:

- **Сфера** — Работа, Личное, Каналы, Спам или **Другое** (без сферы). Контакт может быть сразу в нескольких сферах.
- **Метка (тип)** — например, «Друзья», «Клиент», «Поставщик», «Сотрудник». У контакта может быть несколько меток (и «Друзья», и «Заказчик» одновременно).
- **Папка** — вложенные папки внутри сфер (родитель → подпапка). Контакту можно назначить несколько папок.

Чтобы классифицировать контакт, откройте его карточку → **«Классифицировать»**. Откроется дерево: сферы раскрываются по клику, внутри — папки и подпапки. Отметьте нужные папки (галочки) и нажмите **«Сохранить»**.

**Автосвязь папки и метки:** если вы кладёте контакт в системную папку (например, «Поставщики»), соответствующая метка («Поставщик») добавится автоматически — и наоборот.

В карточке контакта видны **все** сферы (бейджи), **все** метки и **все** папки с полным путём (`Поставщики / Мебель`).

### Спам

Пометка «Спам» — эксклюзивная: контакт помечается спамом, прежние классификации временно скрываются. При снятии спама контакт возвращается к прежним сферам, меткам и папкам.

## 5. Подключение каналов

### Telegram

1. **Каналы** → **Подключить Telegram**.
2. Введите номер телефона в формате `+79123456789`.
3. Введите код из Telegram (или SMS).
4. При двухфакторной аутентификации — введите пароль.

Вход идёт по вашему номеру. API ID/API Hash принадлежат приложению — вводить их не нужно (либо укажите свои в расширенных настройках).

### Email

1. **Каналы** → **Подключить Email**.
2. Укажите адрес, пароль, IMAP-сервер (входящие) и SMTP-сервер (исходящие).
3. Письма подтягиваются в общий инбокс.

## 6. Входящие: каналы и спам

Секции **«Каналы»** и **«Спам»** при входе пустые (не загружаются автоматически). Внутри две кнопки:

- **«Загрузить новые»** — докачать свежие сообщения из Telegram.
- **«Показать загруженные»** — показать ранее загруженные диалоги из базы, без обращения к Telegram.

При загрузке каналов можно выбрать конкретную папку (включая подпапки) — загрузятся диалоги только из неё. Счётчики Telegram/Email в фильтре считаются независимо от выбранного канала.

## 7. Каталог товаров и поставщики

- **Товары** — название, артикул (SKU), цена, закупочная цена, остаток, единица измерения, описание, поставщик.
- **CSV-импорт** — загрузите файл с колонками `name;sku;price;purchase_price;stock;unit;description;supplier`. Повторная загрузка обновляет товары по артикулу, а не дублирует.
- **Поставщики** — список в Каталоге. Поставщик связан с контактом: новый поставщик из импорта автоматически попадает в контакты (папка «Поставщики», метка «Поставщик»), а контакт, положенный в папку «Поставщики», появляется в Каталоге.

---

## 8. Заказы

Канбан со статусами (новый / в работе / отправлен / выполнен / отменён). В заказе — клиент, состав (товары и количество), суммы, комментарии. Заказы привязаны к контактам.

---

## 9. Офлайн-режим и ожидающие сообщения

BiziBox работает и без интернета:

- Скачанные сообщения, контакты и задачи сохраняются локально и доступны офлайн.
- Сообщение, отправленное без связи, не теряется: помечается **⏳ «ожидает отправки»** и уходит, когда появится интернет.

Кнопка **«Ожидает: N»** вверху открывает список: **Изменить** текст, **Отменить** отправку. При неудаче — **«Ошибки: N»** с повтором.

## 10. Резервное копирование

В **Настройках**: **Экспорт** — скачать все данные одним файлом; **Импорт** — восстановить. Рекомендуется делать экспорт регулярно.

---

## 11. Настройки

- **Тема** — светлая / тёмная.
- **Уведомления** — push-уведомления о новых сообщениях.
- **VPN / Прокси** — тот же выбор сети, что при онбординге (напрямую / системный VPN / свой прокси), применяется без перезапуска.
- **Экспорт / импорт** — резервное копирование.

## 12. Установка как PWA на телефон

Откройте приложение в браузере на телефоне (в той же локальной сети) и выберите «Добавить на главный экран» / «Установить приложение». BiziBox поддерживает офлайн-кеш и работает как обычное приложение.

## 13. Частые вопросы

**Где хранятся мои данные?**
Локально, рядом с exe: `data\users\<ваш_логин>\`. База зашифрована (Fernet), в облако ничего не отправляется.

**Как сменить пользователя?**
Кнопка **Выход** внизу бокового меню — пройдёте онбординг заново. Данные прежнего логина сохранятся.

**Почему не приходят сообщения?**
Проверьте **Каналы**: канал должен быть подключён (зелёная отметка). Для Telegram в регионах с блокировками выберите «Свой прокси» или «Системный VPN» в настройках сети.

**У меня системный VPN (OpenVPN/WireGuard) — что выбрать?**
Выберите «Системный VPN» и ничего не вводите: весь трафик уже идёт через VPN, прокси не нужен.

**Как отменить сообщение, отправленное без интернета?**
Нажмите «Ожидает: N» вверху → у нужного сообщения «Отменить».
