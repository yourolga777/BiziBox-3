# BiziBox — описание продукта

**BiziBox** — личное PWA-приложение «сообщения и дела в одном окне». Вся история переписки, контакты, задачи и календарь — локально, приватно, без облака.

## Проблема

Личная переписка размазана по мессенджерам и почте, дела — по заметкам и календарям. Нет одного окна, где видно и сообщения, и дела. При этом личные данные не хочется отдавать в облако.

## Решение

BiziBox собирает входящие из Telegram и Email, связывает их с контактами и задачами, показывает всё в одном календаре. Все данные хранятся локально в зашифрованной базе SQLite.

## Функционал (скоуп v1)

### Входящие
- Единый inbox для Telegram и Email.
- Папки (системные и пользовательские), фильтры по каналу и типу контакта.
- Спам: авто-скрытие, ручная дозагрузка, очистка при выходе.
- Snooze сообщений — отложить до времени, потом вернётся в «Новые».
- Извлечение OTP-кода из сервисных сообщений (кнопка «Скопировать код»).
- Автолинковка URL в сообщениях (безопасная, без XSS).
- Массовые действия: прочитано / архив / удалить.

### Контакты
- Типы контактов: личные, сервисные, спам, прочее.
- Папки, заметки, важность, дни рождения.
- Поиск, объединение дублей.

### Задачи
- Канбан: новые / в работе / выполнено (drag-and-drop).
- Дедлайн, напоминание, повторение (ежедневно / еженедельно / ежемесячно).
- Привязка к контакту.

### Календарь
- Виды: месяц / неделя / день.
- Задачи (цвет по статусу), события, дни рождения.
- Создание/редактирование/удаление событий.

### Напоминания
- Фоновый scheduler (раз в минуту) помечает напоминания, чей срок наступил.

### Прочее
- Тёмная тема (с сохранением).
- PWA: офлайн-режим, установка на телефон, push-уведомления.
- Бэкап и восстановление одним зашифрованным файлом.
- Дашборд: сегодня, просроченное, непрочитанные, диалоги, дни рождения, быстрое создание.

## Вне скоупа v1

- Мульти-пользовательский режим.
- Облачная синхронизация (приложение намеренно локальное).

## Аудитория

Личные пользователи, которые хотят единое приватное окно для сообщений и дел без облачных сервисов.
