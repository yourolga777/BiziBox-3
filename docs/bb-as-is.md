# BiziBox — весь бизнес на одном экране

## Реализовано

1. PWA
2. Поддерживает ВПН пользователя
3. Инбокс – единая лента из Telegram и Email, вложения (pdf, jpg), фильтры по контактам
4. CRM/Контакты — карточки, автосоздание при получении первого сообщения, сферы (Работа/Личное), папки, категории, анти-спам, слияние дублей, заметки, история заказов/задач, импорт/экспорт
5. Заказы, Задачи — создание вручную с нуля + из сообщения + автоматически (по правилам). Статусы, доска канбан, привязка к каталогу, календарю
6. Каталог — товары, цены, остатки (корректировка вручную), импорт/экспорт (с возможностью переопределять столбцы)
7. Оффлайн режим для 1 аккаунта на устройстве – уже загруженные данные доступны локально
8. Авто-получение и отправление, когда появится интернет (ВПН) (очередь)

## AI-модуль

- **9.1** Простая классификация (ключевые слова, вес) — по теме и тексту сообщения, по категории контакта
- **9.2** Автоматическая сортировка: Заказ, Вопрос, Жалоба, Личное, Спам, Другое
- **9.3** Автоматическое создание Заказов, Задач из сообщений
- **9.4** Автоответы на шаблонах, черновики ответов (загружает пользователь)
- **9.5** AI-виджет на дашборде: вводим текст – проверяем категорию, если не согласны – меняем, база обучается (добавляет новые слова, меняет вес, пересчитывает вероятность)
