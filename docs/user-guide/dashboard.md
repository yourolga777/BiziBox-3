# Дашборд

Главная панель — сводка сообщений, задач и диалогов.

## Пульс

- Левый кружок — новые сообщения и новые задачи (просроченные + новые).
- Правый кружок — сколько отвечено и сколько задач закрыто.
- Блок **Сообщения** — сколько сообщений сегодня (без спама и каналов); при нажатии — переход во Входящие.
- Блок **Задачи** — сколько задач не завершено.

## Диалоги

Показываются только **личные** диалоги — с кем вы недавно переписывались.
