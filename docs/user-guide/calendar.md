# Календарь

Календарь показывает задачи, события и дни рождения.

## Виды

- Месяц / неделя / день.

## События

- Создание, редактирование и удаление событий.
- Задачи отображаются с цветом по статусу.
- Дни рождения контактов — автоматически, на каждый год.

## Перетаскивание

Карточку задачи можно перетащить на другую дату.
