# Чек-лист визуальной проверки: демо-режим + режим канала + воронка продаж

Проверяются три доработки:
1. **Демо-режим** — кнопка «Попробовать демо» с предзаполненными данными (Telegram/Email/**VK**).
2. **Режим работы канала** — селектор «Оба направления / Только входящие / Только исходящие».
3. **Воронка продаж** — блок на дашборде по статусам заказов.

Результат по каждому пункту: **пройдено** / **ошибка** (с описанием).

---

## 0. Подготовка

- [ ] Скачать свежий `BiziBox.exe` в отдельную папку, например `D:\BiziBox3`.
- [ ] Запустить `BiziBox.exe` — откроется экран настройки (онбординг), шаг «Telegram».

## 1. Демо-режим

- [ ] На первом шаге онбординга ниже кнопки «Далее» виден блок **«Не хотите настраивать сейчас?»** и кнопка **«Попробовать демо с примерами данных»**.
- [ ] Клик по кнопке → приложение открывается сразу в интерфейсе (без ввода логина/телефона/почты/VK).
- [ ] **Дашборд** — есть непрочитанные, диалоги, задачи, блок «Заказы», «Воронка продаж» с цифрами.
- [ ] **Входящие** — сообщения Telegram, Email и **ВКонтакте** (входящие/исходящие), часть непрочитанные.
- [ ] **Контакты** — клиенты, поставщики, партнёр, личные, контакт из VK.
- [ ] **Задачи** — канбан (Новые / В работе / Выполнено).
- [ ] **Заказы** — канбан по статусам, у заказов состав, суммы, комментарии.
- [ ] **Товары** — каталог аудио-оборудования с SKU, ценами, остатками.
- [ ] **Календарь** — события на ближайшие даты.
- [ ] **Каналы** — пусто, виден интерфейс добавления Telegram/Email/VK.
- [ ] Повторный вход в демо (Выход → «Попробовать демо») пересоздаёт данные без задвоений.

## 2. Режим работы канала

- [ ] **Каналы** → у каждого подключённого канала есть строка **«Режим:»** со списком **«Оба направления / Только входящие / Только исходящие»**.
- [ ] Переключение режима → тост **«Режим канала обновлён»**; режим сохраняется после перезапуска.
- [ ] **«Только входящие»**: отправка по каналу блокируется с ошибкой **«работает только на приём»**, входящие приходят.
- [ ] **«Только исходящие»**: отправка работает, входящие не подтягиваются.

## 3. Воронка продаж

- [ ] **Дашборд** → карточка **«Воронка продаж»** с этапами **Новый → В работе → Отправлен → Завершён**.
- [ ] По умолчанию справа **суммы в ₽**; переключатель **«Кол-во / Сумма ₽»** меняет метрику.
- [ ] Между этапами подпись конверсии **«↓ N%»**.
- [ ] Фильтр **«Всё / Неделя / Месяц»** меняет цифры.
- [ ] Клик по этапу → страница **«Заказы»** с фильтром статуса.
- [ ] Без заказов — заглушка «Нет заказов для воронки», не падает.

## 4. Завершение

- [ ] В `data\logs\bizibox.log` нет `ERROR`, связанных с проверкой.
- [ ] Нет неожиданных тостов ошибок.

---

## Если что-то упало

1. Зафиксируйте: номер пункта, что делали, что увидели (текст ошибки / скриншот).
2. Проверьте, что приложение отвечает: `http://127.0.0.1:<порт>/api/health`.
3. Приложите фрагмент `data\logs\bizibox.log` рядом с моментом ошибки.
