# Частые вопросы

## Где хранятся мои данные?

Локально, рядом с exe: `data\users\<ваш_логин>\`. База зашифрована (Fernet), в облако ничего не отправляется.

## Как сделать бэкап?

**Настройки → Экспорт** — скачать все данные одним файлом. **Импорт** — восстановить из сохранённого файла.

## Как сменить пользователя?

Кнопка **Выход** внизу бокового меню — пройдёте онбординг заново. Данные прежнего логина сохранятся.

## Почему не приходят сообщения?

Проверьте раздел **Каналы**: канал должен быть подключён (зелёная отметка). Для Telegram в регионах с блокировками включите прокси.

## Как отменить сообщение, отправленное без интернета?

Нажмите «Ожидает: N» вверху → у нужного сообщения «Отменить».

## Не приходит код Telegram

1. Проверьте правильность номера телефона.
2. Попробуйте запросить код повторно (или через SMS).
3. Проверьте прокси, если Telegram заблокирован.

## Не удаётся подключить почту

1. Проверьте IMAP/SMTP серверы и порты.
2. Для Gmail может понадобиться пароль приложения (app password).
3. Проверьте, что IMAP включён в настройках почтового ящика.

## Приложение не запускается

1. Проверьте, что порт 7910 не занят другим приложением.
2. Убедитесь, что папка рядом с exe доступна для записи.

## Как сообщить об ошибке?

Создайте Issue на [GitHub](https://github.com/yourolga777/BiziBox/issues).
