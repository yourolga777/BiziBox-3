# Контакты

Карточки людей и сервисов, с которыми вы переписываетесь.

## Типы

- Личные / нужные / спам / прочее.

## Папки

Системные и пользовательские (с подпапками). Папку можно выбрать при создании или редактировании контакта.

## Возможности

- Заметки, дни рождения, важность (избранное).
- Поиск и объединение дублей.
- «Удалить и заблокировать» — новые сообщения от контакта не приходят.

## Классификация у имени

В чате рядом с именем показывается бейдж классификации контакта (Личное / Нужное / Другое / Спам).
