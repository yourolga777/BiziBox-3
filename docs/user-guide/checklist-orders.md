# Чек-лист проверки Модуля «Заказы»

Проверяется модуль **«Заказы»**: канбан с drag&drop, карточка заказа (позиции, комментарии, оплата), создание заказа (в т.ч. из сообщения), CSV-экспорт и офлайн-кеш.

Пройти по порядку. Результат: **пройдено** / **ошибка** (с описанием).

> Автопроверка: backend `tests/test_orders.py`, `tests/test_orders_export_csv.py`, `tests/test_order_extractor.py` + остальной набор — **474 passed**; ruff/mypy чисто.
> Frontend `Orders.test.tsx` + существующие тесты — **187 passed**; `npm run lint` чисто; `npm run build` собирается.
> Таблицы `orders`, `order_items`, `order_comments` создаются миграцией `f7a8b9c0d1e2` автоматически при старте backend.

## 0. Подготовка (запуск из исходного кода)

- [ ] Запустить backend:
      ```powershell
      cd backend
      .venv\Scripts\activate
      python -m uvicorn app.main:app --port 7910
      ```
      В логе — успешный старт без `ERROR`; применилась миграция заказов (если база новая).
- [ ] Запустить frontend (второй терминал):
      ```powershell
      cd frontend
      npm run dev
      ```
      Открыть `http://localhost:5173` (Vite проксирует `/api` на `7910`).
- [ ] Убедиться, что есть хотя бы один контакт (или создать его на странице «Контакты») — нужен для проверки создания заказа.

## 1. Навигация

- [ ] В сайдбаре появился пункт **«Заказы»** (иконка коробки), переход по нему открывает страницу.
- [ ] В шапке страницы заголовок «Заказы» и счётчик «N заказов».

## 2. Канбан и статистика

- [ ] Видны 4 колонки: **Новый · В работе · Отправлен · Завершён**, у каждой цветной маркер статуса.
- [ ] Над канбаном 5 карточек статистики: **Всего, Новых, В работе, Отправлено, Сумма активных** (сумма — в рублях, отображается `₽`).
- [ ] Пустые колонки показывают заглушку («нет заказов»), страница не падает.

## 3. Создание заказа

- [ ] Кнопка **«Создать»** → открывается модал.
- [ ] В поле клиента работает поиск по контактам; можно выбрать существующий контакт.
- [ ] Можно ввести **новый** контакт (имя, телефон) прямо в форме — после сохранения он появится на странице «Контакты».
- [ ] Заполнить «Адрес доставки» и «Способ оплаты» (Карта / Наличные).
- [ ] Выбрать товар, количество, цену; сумма в форме пересчитывается при изменении позиций. Можно добавить несколько строк.
- [ ] Сохранить → тост «Заказ создан», модал закрывается, карточка появляется в колонке **«Новый»** с номером вида `ORD-20260924-0001`.
- [ ] Создать второй заказ — номера различаются, порядковый номер растёт.

## 4. Drag & drop

- [ ] Перетащить карточку из «Новый» в «В работе» → карточка переселилась.
- [ ] Обновить страницу (F5) → карточка осталась «В работе» (статус сохранён на сервере).
- [ ] Перетастить карточку в «Отправлен» и «Завершён» — работает так же.
- [ ] Колонки «Отменён» в канбане нет (статус отмены доступен только в карточке заказа).

## 5. Карточка заказа (детальный просмотр)

Клик по карточке → модал деталей. В нём:

- [ ] Видны: клиент, номер заказа, дата, **статус** (выпадающий список), **тумблер «Оплачен»**.
- [ ] Блок «Адрес доставки» редактируемый — сохраняется (переоткрыть модал → значение на месте).
- [ ] Блок «Способ оплаты» редактируемый — сохраняется.
- [ ] Позиции: **«+ Добавить»** (название, кол-во, цена) → после сохранения строка появилась, **сумма пересчиталась**.
- [ ] Удаление позиции (иконка корзины) → строка исчезла, сумма пересчиталась.
- [ ] Комментарии: написать текст → комментарий появился в списке с датой.
- [ ] Удаление комментария (иконка) → комментарий исчез.
- [ ] Сменить статус селектом → после закрытия модала карточка в канбане переместилась.
- [ ] Тумблер «Оплачен» → состояние изменилось и сохранилось после перезагрузки страницы.
- [ ] Кнопка удаления: подтверждение «Переместить заказ в архив?» → заказ исчезает из канбана.

## 6. Экспорт CSV

- [ ] Нажать **«CSV»** в шапке → скачался файл `orders.csv`, тост «CSV выгружен».
- [ ] Открыть в Excel: данные разбились по колонкам (номер, клиент, товары, сумма, статус, дата); русский текст читается без «крякозябр».
- [ ] Создать второй заказ и выгрузить снова → он есть в файле.

## 7. Заказ из сообщения

- [ ] Открыть «Входящие», выбрать любой диалог с сообщением.
- [ ] В панели действий сообщения появилась кнопка **«+ Заказ»**.
- [ ] Нажать → открылся модал создания, контакт подставлен из сообщения.
- [ ] Если в тексте сообщения распознана сумма — в превью показана строка «Возможная сумма заказа: N ₽».
- [ ] Сохранить → заказ создан, на странице «Заказы» карточка появилась в «Новом».

## 8. Офлайн-кеш

- [ ] Остановить backend (Ctrl+C в терминале backend).
- [ ] Открыть «Заказы» → страница **не падает**, показывает ранее загруженные заказы из кеша (IndexedDB, store `orders`, DB schema v7).
- [ ] Создать заказ при выключенном backend → карточка появляется сразу без ошибок (optimistic-режим).
- [ ] Запустить backend снова → нажать **«Обновить»** (кружок в шапке) → данные с сервера обновились.

## 9. Изоляция по владельцу

- [ ] Проверяется автотестами backend (заказы и позиции другого `owner_id` не видны и не изменяются). Ручная проверка — только если есть второй логин: заказы одного пользователя не видны другому.
