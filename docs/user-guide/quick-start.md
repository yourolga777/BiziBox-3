# Быстрый старт

## Шаг 1: Запустите приложение

Запустите `BiziBox.exe`. Приложение запустится в фоне и откроет браузер с интерфейсом (обычно `http://localhost:7910`).

## Шаг 2: Онбординг

При первом запуске откроется мастер настройки из четырёх шагов:

1. **Telegram** — введите логин (любое имя, по нему создаётся ваша папка данных) и, при желании, номер телефона.
2. **Email** — адрес, пароль, серверы IMAP/SMTP.
3. **Прокси** — SOCKS5-прокси, если нужно (например, для Telegram).
4. **Готово** — проверьте данные и завершите.

Логин можно ввести, а каналы подключить позже в разделе «Каналы». Шаги можно пропустить.

## Шаг 3: Подключите каналы

В разделе **Каналы** подключите Telegram и/или Email — сообщения начнут приходить в единый инбокс.

## Шаг 4: Работайте с сообщениями и делами

- **Входящие** — диалоги, ответы, папки, спам.
- **Задачи** — канбан, дедлайны, повтор по датам.
- **Календарь** — задачи, события, дни рождения.
