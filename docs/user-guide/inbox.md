# Входящие

Раздел **Входящие** — единый инбокс Telegram и Email: личные сообщения, лента, папки, спам.

## Возможности

- **Папки** — системные и пользовательские (с подпапками), фильтры по каналу и типу контакта.
- **Вкладки** — «Все», «Новые», «Каналы», «Спам»; порядок можно менять перетаскиванием.
- **Массовые действия** — отметить несколько диалогов и применить «Прочитано» или «Классифицировать».
- **Спам** — авто-скрытие, ручная дозагрузка, кнопка «Спам» в карточке контакта.
- **Пересылка** — переслать сообщение другому контакту.
- **Ссылки** — автодетекция URL, показ домена (синий → фиолетовый после перехода).

## Ответ и вложения

В диалоге можно ответить (видно, на какое сообщение ответ), отправить файл, посмотреть вложение с предпросмотром.

## Офлайн и «ожидает отправки»

Сообщение, отправленное без связи, не теряется: помечается значком ⏳ и уходит автоматически при восстановлении сети. Кнопка **«Ожидает: N»** вверху открывает список ожидающих (изменить / отменить). При неудаче появляется **«Ошибки: N»** с повтором.
