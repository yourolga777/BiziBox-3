# Подключение каналов

BiziBox поддерживает Telegram и Email.

## Telegram

1. Откройте **Каналы** → **Подключить Telegram**.
2. Введите номер телефона в формате `+79123456789`.
3. Введите код, который придёт в Telegram (или SMS).
4. Если включена двухфакторная аутентификация — введите пароль.

Вход идёт по вашему номеру телефона. API ID/API Hash принадлежат приложению — их вводить не нужно (либо укажите свои в расширенных настройках).

### Прокси / VPN (опционально)

Если Telegram заблокирован, настройте прокси на шаге онбординга или позже в **Настройки → VPN / Прокси**.

| Вариант | Что указывать |
|---------|----------------|
| Системный VPN (WireGuard/OpenVPN TUN) | ничего — выберите «Без прокси» |
| VPN-приложение (v2rayN/Xray/Clash/Happ) | локальный адрес `127.0.0.1:порт` |
| MTProto-прокси | `хост:порт` + `secret` |

Вводите **локальный** адрес, который VPN-приложение открывает на компьютере (обычно `127.0.0.1:10808`), а не IP VPN-сервера.

## Email

1. **Каналы** → **Подключить Email**.
2. Укажите адрес, пароль, IMAP-сервер (входящие) и SMTP-сервер (исходящие).
3. Письма будут подтягиваться в общий инбокс.

### Настройки популярных сервисов

| Сервис | IMAP | SMTP |
|--------|------|------|
| Gmail | imap.gmail.com:993 | smtp.gmail.com:465 |
| Yandex | imap.yandex.ru:993 | smtp.yandex.ru:465 |
| Mail.ru | imap.mail.ru:993 | smtp.mail.ru:465 |
| Outlook | outlook.office365.com:993 | smtp.office365.com:587 |

## Управление каналами

- **Отключение** — иконка корзины на карточке канала.
- **Статус** — зелёный индикатор показывает, что канал активен.
- **Обновить** — кнопка показывает «Загружается...», пока идёт проверка.
