# Задачи

Раздел **Задачи** — канбан со статусами «новые / в работе / выполнено».

## Создание задачи

- Вручную: **Создать** → заголовок, описание, дедлайн, напоминание, повтор.
- Из сообщения: в диалоге «Создать задачу» — заголовок и описание предзаполняются.

## Колонки

- **Просроченные** — слева, задачи с прошедшим дедлайном.
- **Новые / В работе / Выполнено** — карточку можно таскать за любое место (drag-and-drop).

## Повтор

- **По правилу** — ежедневно / еженедельно / ежемесячно, с полем «до какого срока».
- **По конкретным датам** — несколько дат, на каждую создаётся отдельная задача.

## Напоминания

Напоминание за N минут до дедлайна. Когда срок наступает, приложение отмечает напоминание.
