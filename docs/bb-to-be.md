# BiziBox — Запланировано

## Общее

1. Нативное десктоп-приложение: установщик, пуш-уведомления (напоминания, дедлайны задач, заказы, новые сообщения)
2. Авторизация (+ админский аккаунт для сопровождения и поддержки)
3. Многопользовательский режим внутри одной организации (один аккаунт на нескольких устройствах): роли, передача другому сотруднику сообщений, задач, заказов (через импорт-экспорт, без удалённого сервера)
4. Несколько аккаунтов на одном компьютере с офлайн-обвязкой
5. Андроид, Эпл
6. Расширенные каналы: СМС (?), WhatsApp, ВКонтакте, Avito, Ozon/Wildberries
7. Встроенный ВПН
8. Вложения всех форматов + распознавание голоса
9. Правила для сообщений как в почте (если от Васи, Пете – то переслать Пете. Если от неизвестного контакта – отправить автоответ «рады вашему сообщению, ответим в ближайшее время»). Шаблоны ответов (добавляет пользователь) с переменными (имя, заказ/вопрос/тд + каталог)
10. RAG-автоответы (обучается на загруженных переписках) – локальная модель
11. Массовые рассылки, массовые действия в заказах/товарах, >1 каталога
12. Расширенная аналитика: расширенная воронка, тренды/сезонность, время ответа, PDF/Excel
13. Отчёты по менеджерам, КПИ
14. Планировщик постов, генерация текстов, аналитика охватов
15. Интеграции с Учётными системами
16. ЭДО, МПШ ??

## Модуль УЧЁТ

1. Приход/расход ДС (получение данных из каналов, платёжных систем или загружает пользователь, создание операции в учёте)
2. Генерация документов, автозаполнение (по шаблону пользователя: договор, счёт, акт, УПД, заказ поставщику) + расширенная карточка контакта
3. ОПиУ, ДДС

## Модуль СКЛАД

1. Расширенный каталог (цена закупки/продажи)
2. База поставщиков (каталоги, прайс-листы)
3. Полный учёт товаров: приход/расход, история движений, резерв остатков, >1 склад, импорт/экспорт (с возможностью менять колонки) XLSX/JSON
4. Парсинг из Word, Excel, PDF, JPG в каталог (+ автоопределение столбцов)
5. Парсинг входящих (заказы – бронирование из остатков)

## Модуль КАДРЫ

1. Договора
2. Зарплаты
3. Премии
4. Налоги

## АИ-модуль

1. АИ-виджет (API доступных моделей, подключает пользователь) работает в режиме диалога с контекстом сессии
2. Утренний отчёт: саммари по вчерашнему дню
3. Выбрать период – важные письма, задачи, заказы, оплаты
4. Аналитика по данным – запрос отчётов человеческим языком (сколько заказов сегодня, какие товары заканчиваются, сколько потратили за год на туалетную бумагу, кто заказывал водку) + визуал (документ или презентация с графиками)
5. Автоответы: классификация, составление текста + карточка контакта + каталог (остатки, цены), черновики ответов в 3 тонах
6. Клон пользователя (обучение на прошлых переписках и действиях пользователя)
7. Ассистент (автоматически действует сам) включён весь день, следит, создаёт задачи и заказы, напоминает, предлагает, собирает примеры переписки для обучения (автоответы), резерв в каталоге, может отправить счёт, договор…
8. АИ-помощник (внешние модели/локально) работает в режиме диалога с контекстом сессии человеческим языком. В том числе может генерировать документы, делать презентации, красивые отчёты. Может менять визуализацию приложения.
