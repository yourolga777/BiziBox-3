## Запуск прогона

1. Открой `d:\Projects\BiziBox\docs\architecture` в opencode.
2. Для каждого этапа: открой файл этапа, вставь в него блок из `00-context.md`, запусти модель из «Рекомендуемых моделей».
3. Сохрани вывод модели в отдельный файл `results/01-...md` и обнови статус в этой таблице.
4. После всех этапов запусти `06-final-review.md` — сведи результаты.
