# Changelog

Все заметные изменения проекта IziBox документируются в этом файле.
Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версионирование — [SemVer](https://semver.org/lang/ru/).

## [2.1.0] — 2026-09-18

Второй мажорный релиз — доработка онбординга, входящих, задач и офлайн-режима
по итогам пользовательской проверки (Фикс 2.1, 16 пунктов).

### Добавлено

- **Онбординг** — подсказки по VPN (нужен только Telegram), выпадающий список
  email-провайдера с автозаполнением host/port и ссылкой «где взять пароль
  приложения», предзаполнение данных при повторном входе тем же логином.
- **Входящие** — массовые действия по отмеченным диалогам («Прочитано»,
  «Классифицировать»), перетаскиваемые вкладки-фильтры.
- **Пересылка** — переслать сообщение другому контакту (модалка выбора
  получателя + `POST /messages/forward`).
- **Задачи** — колонка «Просроченные» на канбане, повтор по конкретным датам
  (поле `repeat_dates`) и «до какого срока» (`repeat_until`), drag карточки за
  любое место, предзаполнение задачи из сообщения.
- **Дашборд** — «Пульс» (новые сообщения/задачи, отвечено/закрыто, блоки
  «Сообщения» и «Задачи»), «Диалоги» только личные.
- **Ссылки** — автодетекция URL, показ домена, цвет синий → фиолетовый после
  перехода.

### Исправлено

- Предпросмотр и скачивание вложений (файлы отдаются с диска без живого адаптера,
  `Content-Disposition: inline` для изображений/аудио/видео).
- Макет и масштабирование на Windows >100%.
- Индикатор «Загружается» при обновлении каналов.
- Виден ответ на сообщение в чате (`reply_to` у исходящих).
- Вход без интернета с первого раза.
- Авто-восстановление каналов после обрыва связи + сброс офлайн-очереди.
- Классификация контакта рядом с именем; кнопка «Спам» перенесена в карточку
  контакта.

## [2.0.0] — 2026-09-17

Первый мажорный релиз после v1.0.0 — напоминания, темы писем, цитирование
ответов и офлайн-очередь.

### Добавлено

- **Напоминания** — расширенный фоновый scheduler, отметка `reminder_seen`.
- **Темы писем** — subject у исходящих email-сообщений.
- **Цитирование ответов** — `reply_to` у сообщений, `In-Reply-To`/`References`
  в email-адаптере.
- **Офлайн-очередь** — идемпотентная доставка через `client_request_id`,
  outbox-воркер.
- **Блокировка контактов** — `is_blocked` у контакта, скип входящих от
  заблокированных.

### Изменено

- Telegram-адаптер переработан (переподключение, таймауты, реальное время
  доставки).

## [1.0.0] — 2026-08-29

Первый релиз IziBox — личное PWA-приложение «сообщения и дела в одном окне».

### Добавлено

- **Единые входящие** — общий инбокс Telegram и Email: лента, диалоги по
  контактам, папки и каналы, прочитано/непрочитано, вложения с предпросмотром
  и скачиванием.
- **Канальные адаптеры** — Telegram (Pyrogram, SOCKS5-прокси, 2FA в онбординге,
  извлечение OTP-кода) и Email (IMAP/SMTP, вложения, In-Reply-To/References).
- **Контакты** — карточка контакта, типы (личные / сервисные / спам / прочее),
  папки, заметки, дни рождения, объединение дублей.
- **Задачи** — канбан (новые / в работе / выполнено), дедлайны, напоминания,
  повторяющиеся задачи.
- **Календарь** — задачи, события и дни рождения; виды месяц / неделя / день.
- **Напоминания** — фоновый scheduler по задачам.
- **Бэкап** — экспорт/импорт всех данных одним зашифрованным файлом.
- **Безопасность** — локальные данные (SQLite + Fernet-шифрование), ничего
  не уходит в облако.
- **PWA** — офлайн-кеш, установка на телефон.
- **Офлайн-режим** — кэш сообщений и контактов, очередь мутаций, авто-отправка
  при восстановлении сети, панель «Ожидает отправки» с отменой и изменением
  ожидающих сообщений.
- **Удобство** — глобальный поиск, тёмная тема, push-уведомления, snooze,
  автодетекция ссылок.
- **Доставка** — portable-сборка PyInstaller (один `IziBox.exe`), установщик
  Inno Setup, CI-публикация GitHub Release по тегу `v*`.

### Изменено

- Проект переименован из BiziBox в IziBox (бренд, пакет, инсталлятор, CI,
  portable-режим, трей).
- Удалены модули, не входящие в продуктовую концепцию: AI-классификация,
  заказы, каталог, категории, правила сообщений, шаблоны, поставщики.
